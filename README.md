> Moodboard & color token archive for organizing visual direction, color swatch extraction, and design inspiration grids.

---

## 🚀 Installation & Launch

Install `mood-archive` launcher shortcut via Josephan installer:

```bash
curl -fsSL install.josephan.dev | bash
```

Or run locally:

```bash
npm install
npm run dev
```
